# Kernel Panic

*A paddle, a ball, and a screen full of trouble.*

Kernel Panic is a 2D arcade game inspired by Breakout and Arkanoid. Your paddle is a security barrier, your ball is a data packet, and those blocks? Viruses that need to go.

Bounce the packet, clear the threats, and work your way through the system. Each stage gets a little tougher, so keep an eye on where that packet is heading.

Made for quick rounds, whether you're chasing a better score or just taking a break.

Currently in development for desktop computers as a college project at IFSC (Instituto Federal de Santa Catarina).

## Project status

**In development.** This is coursework in progress, not a finished game. Expect placeholder art, missing systems, and things that change from one commit to the next.

## Built on a template

The project started from a base template provided by **professor Ignacio Sepúlveda**, used in class as the starting point for the game. The template supplies the initial Godot project setup and the basic Breakout-style structure; everything built on top of it is the work of this project.

## Built with

- [Godot Engine 4.7](https://godotengine.org/) — Forward+ renderer
- GDScript
- Jolt Physics (engine default)

## Running the project

1. Install [Godot 4.7](https://godotengine.org/download) (standard version, no C# needed).
2. Clone this repository.
3. Open Godot, click **Import**, and select the `project.godot` file in the project root.
4. Press `F5` to run. The main scene is `scenes/jogo.tscn`.
